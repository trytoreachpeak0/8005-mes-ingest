# MesIngest 使用 SIMPLE 恢复且不保留数据库备份

MesIngest 的详细历史只承诺 15 天，用户选择以最低磁盘占用和最少维护换取不具备数据库灾难恢复能力。决定新库使用 SIMPLE 恢复模式，不创建完整、差异或事务日志备份；数据库损坏或丢失后重新建立空库，15 天历史、当前投影及 ArchivedDemandKeyTombstone 均不可恢复，并从新的完整成功 MES 轮次重新开始历史。

**Status**: accepted

**Consequences**:
- 本决定不同于 ADR-mes-0021 的计划切换墓碑播种：非计划数据库丢失没有旧库来源，既有归档键会被遗忘，后来重现可能被解释为新 Series。
- FULL 恢复模式和无日志备份的组合被禁止；SIMPLE 模式仍需监控事务日志实际大小与重用等待。
- Host 不得把数据库重建伪装成普通重启；是否允许外部目录在历史身份丢失后重新开放需要独立恢复决策。
