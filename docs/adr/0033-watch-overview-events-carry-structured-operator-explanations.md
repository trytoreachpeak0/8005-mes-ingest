# Watch 概览事件携带结构化操作员解释

WatchOverviewSnapshot 中的近期动态必须与事件本身在同一冻结快照内携带结构化 OverviewAttentionExplanation，使 Watch 能直接说明具体转换或错误原因并按语义下钻。拒绝由 Watch 为每行追加详情请求，因为那会形成 N+1 读取并把不同投影时点混入同一概览；也拒绝只显示技术大类或原始事件码。解释只携带有界的最小诊断事实，完整原始证据仍留在目标详情页。

Watch 以“事件结论、原因解释、带标签的定位信息”三层呈现每项：已知 WorkType 在正常中文界面使用中文业务名，原始代码和完整标识留给复制、悬浮或技术详情；未知事件用中文升级提示且不静默丢弃。错误事件进入错误检索，生命周期事件进入系列详情，轮询与保护事件进入对应当前关注范围。严重度不能只靠颜色：错误使用红色错误形状和文字，警告使用琥珀色警告形状和文字，恢复使用绿色状态，普通转换使用中性或蓝色信息状态；错误期间结束必须依据结束原因区分真正恢复、需求消失和系列归档。
