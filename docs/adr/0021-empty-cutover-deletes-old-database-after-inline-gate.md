# 空库切换通过同窗门禁后立即删除旧库

新版有界历史库除 ArchivedDemandKeyTombstone 外不迁移当前 MesIngest 数据，且继续保留旧库或备份会抵消释放存储的目标。决定在一次 30–60 分钟计划停机窗口中建立空库，先从旧库播种已归档 TransportDemandKey 的最小墓碑，再完成 schema 校验、连续三轮成功 MES 投影、主要 Watch 读取与外部目录检查并立即删除旧库，不创建或保留回滚备份；以不可恢复的旧详细历史删除换取明确的新历史起点和即时空间回收，门禁通过后只能向前修复。

**Status**: accepted

**Consequences**:
- 新 Host 第一次启动成功不足以授权删除；全部同窗机械门禁必须先通过并留下结果。
- 归档业务键墓碑是安全否定事实而非可浏览历史；切换门禁必须证明旧库全部已归档键在新库存在且不会进入外部目录。
- 新行为先在独立空库和整包 Host/Watch/reference consumer 上完成 15 天规模验证；旧服务恢复只用于只读基线和最终差分，不原地升级、不双写，也不承担新 schema 的中间态。
- 旧库删除只能由 ADR-mes-0030 定义的一次性 MesIngestCutoverRun 在同窗门禁通过后自动执行；日常 Host 不拥有或调用该能力。
- 删除旧库后不存在版本或历史回滚路径，故障只能在新库和新契约上修复。
- 该决定收窄 ADR-mes-0017 所述“通过整套旧部署及独立备份回退”的可能性：本次切换明确不保留那项资产。
