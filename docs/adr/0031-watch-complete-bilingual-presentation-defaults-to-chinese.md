# Watch 提供完整中英文呈现并默认中文

Status: superseded in part by ADR-mes-0032

MesIngestWatch 的主要用户是开发人员，但界面仍需保持一致、可快速解释。决定提供完整的简体中文与英文切换，首次启动固定使用中文而不跟随 Windows 显示语言，用户可在设置中单独调整；该选择属于 Watch 本机显示偏好，不改变 Host 或业务数据。界面结构、业务语义、状态含义、错误说明、单位和空状态均参与翻译；`MesIngest Watch`、`Host`、`MES` 以及 `SUBLOT`、`AREA`、`EQP`、`STEP`、`DATES`、`PACKAGE` 等外部系统或源字段保持原名。协议码、错误码与稳定标识保留原值，并与本地化含义同时显示，原值采用次要技术信息层级。

Watch 同时采用“禁止孤立值”的呈现约束：每个值必须由可见字段标签、表头、卡片标题与单位，或其它明确的语义锚点解释；已有清晰表头时不重复标签，无表头条目和多值摘要必须显式标明各值含义，Tooltip 不能代替可见语义。

双语范围覆盖主窗口、Inspector、设置、对话框、通知、Tooltip、复制结果中的说明性列头，以及无障碍名称和帮助文本；API 字段、日志正文、JSON、稳定代码和配置键不翻译。用户在设置中保存语言后，全部已打开窗口立即一致切换，并保留当前页面、筛选、选择、滚动位置与 Inspector 调查上下文。生产 UI 的可见文本来自同一个集中、强类型的双语文本目录，不再在 XAML 或 C# 中新增硬编码文案；发布门禁要求每个资源键及已知状态说明同时具备中文和英文。运行时遇到未知动态代码时显示本地化的未知状态说明并附原始码，不能把未知码隐藏或误当成已有英文文案。

UI 术语以 `CONTEXT.md` 的规范概念建立中英文一一对应，不使用“Demand 世代”“Series 详情”等混合复合词；需要与代码对照的属性以本地化标签为主，并附 `DemandId` 等原始字段名。概览主指标由卡片标题解释对象，大号值必须带单位，次要说明必须交代 AREA、投影提交或目录修订号等统计范围和时点。多值身份摘要使用带标签的紧凑键值对，空间不足时按完整字段换行；必要截断必须同时提供完整 Tooltip 和复制操作。资格审计等既有无表头 master-detail 列表保留已选信息层级，但每个身份、状态和阻断值都使用行内标签，不再依靠字段位置解释。

缺值呈现必须区分来源未提供、系统未知、不适用、尚未加载、查询成功但无结果以及读取失败；不能继续用同一个破折号掩盖这些不同事实，也不能把失败或加载中伪装成空结果。

语言切换只改变呈现，不改变诊断数据或查询语义。绝对时间统一显示为 `yyyy-MM-dd HH:mm:ss zzz` 并保留时区偏移，相对时间只能作为本地化次要说明；标识、原始值和代码不做文化相关转换，数量单位随界面语言切换。筛选项同时显示本地化含义和规范代码，但发送给 Host 及保存在当前筛选状态中的始终是规范代码；切换语言不得重置筛选或重新解释代码。

语言入口位于“设置 → 显示与布局”，选项固定以自称显示为 `简体中文` 和 `English`，首次启动使用简体中文，选择按当前 Windows 用户持久化。开发过程可以分模块迁移，但只有全部页面、详情、通知、复制说明和无障碍文本具备完整双语资源且消除孤立值后才能作为一个版本发布，不提供语言混杂的过渡发布。

发布门禁还必须覆盖：生产 XAML 与 C# 不新增硬编码可见文案；全部已知状态和错误码具备双语含义；未知码保留原值并使用本地化回退；六种缺值、加载和失败语义可区分；概览指标、身份摘要和无表头列表均有明确语义锚点；即时切换语言不丢失页面、筛选、选择、滚动位置或 Inspector 上下文；中文和英文在相同数据与相同窗口尺寸下分别完成视觉检查。
