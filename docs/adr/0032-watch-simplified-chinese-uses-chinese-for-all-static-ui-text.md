# Watch 简体中文模式的固定界面文字全部使用中文

MesIngestWatch 继续提供简体中文与英文两种显示语言，但简体中文模式不再为产品名、系统名、领域类型、属性名、源字段名、状态名或技术说明保留英文例外。标题、标签、表头、筛选项、设置、通知、提示、复制列头和无障碍文本统一采用 `CONTEXT.md` 的规范中文；例如界面名称使用“制造执行系统接入运维台”，Host 使用“服务端”，Inspector 使用“调查窗口”，DemandSeries、TransportDemand、DemandId、WorkType、SUBLOT、AREA、EQP、STEP、DATES、PACKAGE 分别使用“需求系列”“运输需求”“运输需求标识”“工序类型”“子批次”“区域”“设备”“下一工序”“来源时间”“封装形式”。中文界面的语言选项显示为“简体中文”和“英语”。

运行时值仍保持原样，包括标识、稳定代码、工序类型值、制造执行系统原始字段值、时间、路径、命令、日志正文、JSON 内容和其它可复制技术证据。简体中文模式的普通卡片、筛选、状态、列表、提示、通知和无障碍文本对已知代码只显示中文含义，不再以括号、点号或其它形式追加原始代码；例如 `NOT_READABLE` 显示为“不可读”，`GONE` 在数量摘要中显示为“已消失”。原始代码只保留在明确标注的代码字段、原始证据、复制内容与未知码回退中，不得混入人阅读的主语义层。English 模式继续使用完整英文呈现并保持现有代码对照，语言切换、偏好持久化、筛选与调查上下文保持契约不变。Variant A 仍是资格审计的布局与信息层级权威，本决定只替换简体中文语义层。

本决定取代 ADR-mes-0031 中允许 `MesIngest Watch`、`Host`、`MES`、源字段名和原始属性名作为简体中文界面固定文字的例外；ADR-mes-0031 的完整双语、原始值不变、无孤立值和状态保持要求继续有效。
